# MedicalTreatmentApp

## Description
MedicalTreatmentApp est une application JavaFX de suivi de traitements médicaux.

Le projet permet de gérer :
- les patients ;
- les traitements médicaux ;
- les statistiques ;
- les paramètres de l'application ;
- l'export des données en CSV.

## Technologies utilisées
- Java
- JavaFX
- FXML
- CSS
- MySQL
- JDBC
- Git / GitHub
